# Holiday Roulette ✈️🎰

Pick a budget, choose your vibe, set your trip length, then spin the wheel to find out where you're going on holiday.

- 51 destinations across 5 budget tiers (Shoestring → Money No Object)
- Vibe filters: beach, city, adventure, culture, foodie, snow
- Each result shows flight time and a typical return fare from the UK, daily spend, a trip total and four things to do
- Mystery mode, sound effects, no-repeat spins and passport stamps

It's a single static `index.html` with no build step.

All prices and flight times are rough estimates, not live quotes.
